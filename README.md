# The-Endless-Maze
A compact, pocket-sized gaming gadget using a Seeed Studio XIAO Esp32 s3 and an OLED display. It uses the onboard IMU accelerometer/gyroscope for tilt-controlled games—specifically a dynamically generated endless maze—housed in a custom 3D-printed enclosure with a rechargeable LiPo battery.
